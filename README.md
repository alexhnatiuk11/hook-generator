# Hook Generator

MVP утиліта для SockLock MarTech case: знімає вузьке місце креативного продакшену
(дизайнер витрачає ~половину часу на ручний ребрейндинг hooks / перших фраз /
on-screen текстів для кожної нової модифікації креативу).

## Проблема і гіпотеза

- Щоб вийти на $800k spend / міс потрібно ~500 модифікацій/міс замість поточних 240.
- Без змін це ~1980 год дизайнерського часу/міс (зараз ~1200 год).
- Генерація варіантів хуків/фраз зі скрипта переможця скорочує одну модифікацію
  з ~3 год до ~2 год → потреба падає до ~1480 год/міс.

## Як працює (MVP)

Streamlit-сторінка:

1. Дизайнер вставляє (або завантажує .txt) скрипт переможного креативу.
2. Опційно завантажує CSV з уже протестованими хуками (колонки: `hook`, `angle`, `status`)
   — модель уникає повторів і орієнтується на те, що вже виграло/програло.
3. Обирає кути подачі (Біль, Сценка з життя, Гроші, Обмежена пропозиція, Соціальний доказ) і кількість варіантів.
4. Натискає «Згенерувати» → отримує таблицю на екрані + CSV для скачування
   (готово для імпорту в Airtable).

API-ключ зберігається на сервері (`.env`), не в браузері.

## Встановлення

```bash
pip install -r requirements.txt
echo 'ANTHROPIC_API_KEY=your_key_here' > .env
```

## Запуск

```bash
streamlit run app.py
```

Приклади вхідних файлів: `sample_script.txt`, `sample_tested_hooks.csv`.

## Повна версія (поза скоупом MVP)

Кнопка прямо в Airtable: дизайнер натискає «Згенерувати модифікації» на картці
переможця, автоматизація Airtable викликає serverless-функцію → LLM → записує
нові рядки назад у таблицю зі статусом «Нове». Бібліотека протестованих хуків
теж береться з Airtable автоматично.

## Обмеження MVP

- Немає валідації якості/бренд-войсу варіантів — дизайнер сам відбирає придатні.
- Оцінка "1 год заощаджено на модифікацію" — попередня, не підтверджена
  виміром на реальних дизайнерах; потрібен пілот для перевірки.
